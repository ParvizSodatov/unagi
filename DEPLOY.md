# Деплой «Унаги» (временный, бесплатный)

Схема: **бэкенд на Railway** (триал $5, ~месяц работы, данные сохраняются на volume) + **фронтенд на Vercel** (бесплатно бессрочно).

## 1. Бэкенд → Railway

1. Зайди на [railway.com](https://railway.com), войди через GitHub (карта не нужна, дают $5 триала на 30 дней).
2. **New Project → Deploy from GitHub repo** → выбери эту репу.
3. В настройках сервиса (**Settings**):
   - **Root Directory** → `backend` (важно, у нас монорепо!)
   - Start Command можно не трогать — `npm start` сам засеет базу при первом запуске.
4. Подключи диск: правый клик по сервису → **Attach Volume**, mount path: `/data`.
5. Вкладка **Variables** — добавь переменные:

   | Переменная | Значение |
   |---|---|
   | `DATA_DIR` | `/data` |
   | `JWT_SECRET` | любая длинная случайная строка |
   | `ADMIN_LOGIN` | логин админа (иначе будет `admin`) |
   | `ADMIN_PASSWORD` | пароль админа (иначе будет `admin123` — смени!) |
   | `CORS_ORIGIN` | адрес фронта на Vercel, напр. `https://unagi.vercel.app` (можно добавить позже) |
   | `TELEGRAM_BOT_TOKEN` | (опционально) токен бота |
   | `TELEGRAM_CHAT_ID` | (опционально) чат для оповещений |

6. **Settings → Networking → Generate Domain** — получишь адрес вида `https://unagi-production-xxxx.up.railway.app`. Проверка: открой `<домен>/api/health` — должно вернуть `{"ok":true}`.

## 2. Фронтенд → Vercel

1. Зайди на [vercel.com](https://vercel.com), войди через GitHub.
2. **Add New → Project** → выбери эту репу. Конфиг сборки уже лежит в `vercel.json` (корень репы, ничего менять не надо).
3. В **Environment Variables** добавь:

   | Переменная | Значение |
   |---|---|
   | `VITE_API_URL` | `https://<твой-домен-railway>/api` |

4. Deploy. Получишь адрес вида `https://unagi-xxx.vercel.app`.
5. Вернись в Railway и впиши этот адрес в `CORS_ORIGIN` (без слэша на конце) — сервис перезапустится сам.

## Как это устроено

- База SQLite и загруженные фото лежат в `DATA_DIR` (`/data` на volume Railway) — переживают рестарты и деплои.
- При каждом старте сначала выполняется сид (`src/seed.js`) — он идемпотентный: если данные уже есть, ничего не трогает.
- Локально ничего не поменялось: без `DATA_DIR` база и `uploads/` живут в `backend/`, как раньше.

## Когда триал Railway кончится (~через месяц)

Варианты переезда:
- **Render.com free** — бесплатно бессрочно, но диска нет: база будет сбрасываться при рестартах (сид восстановит меню, но заказы пропадут) и сервис засыпает после 15 минут простоя.
- Дешёвый VPS / оплата Hobby-плана Railway ($5/мес) — когда проект пойдёт в прод.
- Перед переездом забери данные: файл `/data/unagi.db` и папку `/data/uploads` можно скачать через `railway ssh` или временный эндпоинт.
